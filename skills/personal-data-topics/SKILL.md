# 个人资料选题研究

把个人资料中的反差、联系和持续关注，发展成可研究、可解释、可展示的内容选题。题材可以通向历史、人物、市场、文化和公开的幕后故事；个人数据是入口，不要求成稿围绕本人经历叙述。

## 选择范围与读取资料

- 遵循用户本次的范围。用户要求扩展整个资料库时，从全库寻找线索，不继续围绕上一座城市、一个导演或一张图片展开。
- 先识别现有输入和字段含义，按需读取文件。缺少关键资料时询问最小必要信息，同时推进不依赖该信息的研究。没有个人资料时，先提供明确标为“待验证”的研究方向，不编造个性化发现。
- 读取 [workspace.md](references/workspace.md)，按当前项目定位个人资料、选题库与表达偏好。路径或资料未提供时从当前工作区和用户输入查找，不预设个人记录。
- 电影任务读取 [movies.md](references/movies.md)。阅读、跑步、旅行博物馆、足球及跨领域任务读取 [other-domains.md](references/other-domains.md) 中相关部分。后者是数据要求和边界说明，不代表已有完成的数据接入。

## 从资料到题目

1. 明确记录的粒度、覆盖范围、关键字段缺失、身份键和时间含义。保留原始导出；清洗、补充与计算写入派生文件。用对象ID优先匹配，同名不自动合并。
2. 结合定量线索与原文找问题：高低评价反差、重复合作、同一对象前后变化、同年或同类对象的差异、个人选择与公众评价的分歧、跨领域关联。日期和分数只有能帮助回答问题时才进入展示。
3. 候选题至少关联具体记录或明确的数据获取计划。用户未限定数量时按证据提供适量不同角度；不要为凑数量生成同一题的多个改名版。
4. 先验证标题假设，再整理故事。观察到联系不等于因果；评分差不等于质量高低；未取得数据时把结论写成待检验的问题。旧评论证明个人曾表达某种观点，不自动证明其中的历史或科学断言。
5. 针对候选补充外部资料，优先原始数据、官方演职员／赛事／馆藏资料、当事人完整采访和可信研究。记录来源URL、采集日期、数据期间、口径与具体支持的结论。找到互相冲突的数字时追查差异或暂不采用，不默默挑选最吸引人的值。
6. 定性比较个人依据、故事新意、资料可得性、可视化适配和与旧内容的重复度；给出推荐理由和主要缺口。除非用户要求，不制造伪精确的综合得分或流量预测。

## 输出与维护

- 选题列表：工作标题、核心问题、具体个人依据、比较维度或关系、展示方式、缺口、成熟度。已核对事实、个人解读、待验证假设保持可辨认。
- 深入单题：按 [topic-card.md](references/topic-card.md) 形成研究卡，包含证据与图表方案；根据任务裁剪，不为字段完整而填造信息。
- 保存或维护选题库时，使用用户当前项目内的权威文件。保留稳定编号和已有记录；相同证据换角度时说明关联，避免重复制作。
- 状态按实际进度使用“储备／研究中／可制作／已制作／已发布／暂缓”；生成图片不等于已发布。只有用户确认或可靠发布记录才能标为已发布。
- 输出应简明、具体。参考个人写作风格，重新组织观点，不拼接旧评，不把反驳性评论删成单纯推荐。
- 只有用户要求进入制作时才生成正式图文；需要时使用当前可用的图表、图像、文档等工具或技能。研究和拟稿不自动授权发布、发送消息或修改外部内容。
- 小红书新题研究遵循项目活动规则；详细流程见 workspace 参考文件。活动无法读取时记录限制并继续其他研究，不用往期规则冒充本期规则。
