# 电影数据与研究规则

## 先识别数据

以豆瓣条目ID或可核实的影片ID关联数据。区分电影、短片、纪录片、剧集、季与版本；同名作品并非重复记录。《喜剧之王》的周星驰版与斯科塞斯版就是不同作品。

区分已看、想看、在看。空白评分不记为0，不以选入片单推断喜欢。五星制折成十分制仍是粗粒度个人评分，不能把它当与平台均分同样精细的连续测量。

标记日期不等于观看日期、首看日期或重看日期；同日大量记录可能来自补标。单次导出不能还原修改评分、重看次数或完整的想看转已看过程。上映日期要区分电影节首映、当地首轮和内地上映。

从混合“影片信息”解析出的导演、演员、国家字段需抽查；遇到错位及时标记。导演、监制、制片、投资、主演分别记录。单元片与剧集需标明具体参与范围，不能用“第一导演”代表完整职业履历。演员字段可能截断，不当完整演职员表。

## 可用的研究方式

| 维度 | 可以寻找的问题 | 口径与边界 |
| --- | --- | --- |
| 个人评分×大众评分 | 哪些作品评价分歧最大，旧评能否解释 | 大众评分统一采集日期，保留评分人数；当前分数不是历史分数。 |
| 个人评分×票房 | 市场热度与个人偏好何处相遇或分开 | 同一市场、币种、期间、服务费及重映口径；跨年补市场背景或同年排名。 |
| 导演／演员×作品 | 合作网络、角色变化、作者生涯转折 | 先核实署名和作品类型，列样本量及已评分数量；评分不能归因于单个演员。 |
| 上映年×标记年 | 记录中的新旧片构成如何变化 | 使用“标记记录”的表述，不能宣称实际观看延迟或观影渠道。 |
| 短评×评分 | 哪些作品留下更多批评、知识补充或联想 | 字数只是筛选线索；清除“有用”等导出附带项，人工读原文。 |
| 想看×已看 | 哪些导演或主题还欠哪些作品 | 片库内覆盖率不等于全集完成率；先取得全集分母才能这样命名。 |
| 地点×影片×导演 | 拍摄地、故事地、导演偏好怎样相连 | 地点关系逐条标记，制作国家、片名、导演籍贯均不能替代发生地。 |
| 原作×翻拍／改编 | 相同故事在不同市场如何变化 | 核实版权或正式改编关系；相似、致敬、个人联想与抄袭指控不能混用。 |

数据规模小或缺失严重时做影片对读和证据卡，不硬算相关性、平均分排行或回归。跨多城市涉及同一影片时，说明多地点计数规则，避免无意重复累计。

## 票房、历史与幕后

票房不等于观影人次、观众人数或净利润。预算与宣发费、发行分账范围不同；不能把票房除预算叫投资回报率。年度榜票房和累计总票房分开；不能因有票价数据就未经口径核对反推精确人次。

“当年惨败”“拯救行业”“首次”“最高”等标题需历史证据和比较范围，不能照搬宣传稿。选择题材有争议也可成立，但把争议作为研究对象，保留不支持标题的证据。

选角、换角、档期、片酬、制作纠纷和公开合作可作为幕后故事。区分当事人说法、文件事实、媒体转述、未经证实传闻；不把电影情节、人物关系或评分推成现实中的私人指控。

可查官方演职员、出品／发行资料、电影节档案、猫眼等市场数据和可靠采访。Wikidata P915（拍摄地）与P840（故事地）只能作为候选线索，覆盖率和证据另核。第三方开源采集器不等于稳定的官方API，未经测试不承诺批量获取能力。

## 从线索到成稿

例如：个人片库中的银河映像高分作品 → 核对演员交集 → 按真实合作关系画网络 → 找出职业角色与公司历史问题。每条边注明关系种类，不把间接扶持全部写成直接投资。

个人评分差异可以提供观点，但不能证明美学偏好的因果。必要时写“这几篇评论中反复关注……”而非“数据显示作者始终偏爱……”。
