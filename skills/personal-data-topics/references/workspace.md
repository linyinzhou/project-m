# 工作区资料与发布场景

按当前项目的 AGENTS.md、用户提供的路径和会话授权定位资料。无需预设作者姓名、机器路径、数据规模或评分。

## 资料入口

- 确认原始数据、派生数据、选题库与历史产物各自的位置，原始导出保持不变。
- 豆瓣常见字段为状态、豆瓣条目ID、片名、我的评分(10分)、标记日期、短评、影片信息；以实际文件为准。
- 本仓库的 `topics/topic-library.md` 是公开的32个方向种子，不是某个人的统计结论。使用前用真实数据检验，个人研究结果保存到用户指定的项目文件。
- 既有产物不证明已经发布。写作偏好从用户指令和其授权使用的样例读取，不编造经历。
- 技能目录可以单独安装。选题库未一同提供时照常执行研究，不依赖该文件才能运行。

## 小红书活动

新选题用于小红书时，按项目要求查看 https://creator.xiaohongshu.com/new/events ，有读取已登录浏览器的能力时优先使用。核对本期期限、主子话题、内容形式、参与入口、旧笔记参与规则、奖励和评选条件。

无法取得活动详情时说明限制并继续独立研究，不由页面为空判断活动不存在，不拿旧规则代替本期规则。区分承诺的奖励、明确流量扶持和可能的展示机会。仅整理已有选题或维护技能无需逐题重查活动。

研究、拟稿与拟定标签不代表授权发布或修改外部内容。
