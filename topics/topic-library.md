# 个人资料驱动的选题方向

公开版种子库，含32个工作题目。各项均为待检验的研究方向，不代表已经取得个人数据或证明了标题结论。使用技能时结合用户实际片库、笔记与授权资料筛选；不得把示例当成用户经历。

| 编号 | 工作标题 | 比较方式与展示 |
| --- | --- | --- |
| D01 | 为什么港片里，总是这几张熟面孔？ | 影片×演员矩阵、重复合作关系图，带出银河映像历史。 |
| D02 | 刘德华“投”出的电影圈，有多大？ | 人物—作品关系图，分别标明投资、监制、执导、主演和其他帮助。 |
| D03 | 同一批巨星，为什么拍出了两部相反的武侠片？ | 演员与角色对照、制作时间线，讲王家卫和刘镇伟的合作。 |
| D04 | 哪些导演，看得最多，却打分最严？ | 已看数量×个人评分分布；同时展示已评分样本量。 |
| D05 | 电影越来越卖座，导演却越来越不合口味？ | 按上映年份并列票房与评分，挑选背离节点。 |
| D06 | 一位导演，在哪部电影开始失去信任？ | 作品时间轴＋评分差异＋短评中的判断依据。 |
| A01 | 最喜欢的演员，可能一直没被注意到 | 出现次数、高分作品数、合作导演数量并列。 |
| A02 | 同一个演员，换了导演像换了个人？ | 演员×导演×角色矩阵，结合代表表演和个人评分。 |
| A03 | 从配角到主角，一位演员的转折发生在哪部？ | 角色规模、上映年份、票房、奖项的职业时间线。 |
| A04 | 黄金搭档分开以后，电影发生了什么变化？ | 合作期与独立作品对照；票房、评分、类型变化。 |
| A05 | 如果当年换了另一个演员，这部电影会怎样？ | 已证实选角时间线＋最终角色；设想单独标明。 |
| M01 | 票房最高的电影，是最喜欢的吗？ | 票房×个人评分散点图，标出反差影片。 |
| M02 | 后来成为经典的电影，当年卖得好吗？ | 首轮票房、当年排名、后续重映与评价的时间线。 |
| M03 | 获奖、卖座、五星：三张榜单为什么很少重合？ | 三组交集、代表影片对照。 |
| M04 | 小成本黑马，真的更容易让人惊喜？ | 预算、票房、个人评分对照，解释宣传中的回报叙事。 |
| M05 | 同年上映的两部电影，为什么走向完全不同？ | 同年对照：发行规模、票房、影片空间与创作取向。 |
| M06 | 电影在本地拍，本地观众会更买账吗？ | 影片在该城的票房份额，与该城同期全国市场份额比较。 |
| P01 | 这些电影，豆瓣很喜欢，个人评分却不高 | 个人分－大众分的差值榜，挑几部解释。 |
| P02 | 看了这么多年，五星越来越少了吗？ | 年度评分分布、评分覆盖率与影片类型并列。 |
| P03 | 给了低分，为什么还写了那么长的短评？ | 评分×短评长度四象限，挑选有解释价值的反差。 |
| P04 | 新片看得越来越少，还是老片补得越来越多？ | 标记年×上映年代热力图，展示记录中的新旧片构成。 |
| P05 | 想看片单，究竟欠了哪些导演？ | 导演的已看／想看清单与数量。 |
| H01 | 翻拍之后，电影到底丢掉了什么？ | 原作／翻拍成对比较人物、结局、时长、个人评分和市场。 |
| H02 | 两部《喜剧之王》，为什么会走向《小丑》？ | 角色处境、成名欲望和表演的对读图。 |
| H03 | 原著越喜欢，电影就越难打高分吗？ | 从短评提取明确读过的改编作品，比较改动与评价。 |
| H04 | 一部电影里的致敬，能连出多大的电影史？ | 电影—被联想作品的关系图，分“创作者确认”与“个人解读”。 |
| C01 | 电影把观影地图带到了哪些地方？ | 两层地图：数量、个人评分、代表影片；缺失地理信息显式保留。 |
| C02 | 喜欢的是一个地方，还是拍它的那个导演？ | 城市×导演矩阵，同城不同导演、同导演不同城市对读。 |
| C03 | 电影里的广州：没有地标，为什么更像广州？ | 生活空间对照＋个人评分＋取景资料。 |
| C04 | 电影里的杭州：同一位导演，8分与4分之间 | 富春江／西湖茶山、家庭／情节结构的双片对照。 |
| C05 | 电影里的深圳：两部片都只给6分，差在哪？ | 深港跨境生活与深圳创业故事对照。 |
| C06 | 电影里的城市：拍出生活，还是拍成城市名片？ | 广州、深圳、长沙跨城对读，讨论城市表达为何可信或失效。 |

成熟度、个人证据和发布状态应保存在用户自己的研究库中。电影史、票房、合作和幕后资料逐项核实；同名作品按ID区分；标记日期不等于观看日期，缺失评分不等于0分。
